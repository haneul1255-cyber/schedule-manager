# 합주 시간 맞추기

밴드 멤버들의 가능한 시간을 모아 합주 시간을 쉽게 정하는 when2meet 스타일 웹앱입니다.
곡마다 참여 멤버가 다른 밴드 특성에 맞춰, **곡 단위로 모일 수 있는 시간**을 바로 확인할 수 있습니다.

🔗 **사이트: https://schedule-manager-6t3.pages.dev/**

## 주요 기능

- **방 만들기** — 날짜 여러 개와 하루 시작·끝 시간을 정하면 30분 단위 시간표가 만들어집니다.
- **초대 링크로 참가** — 링크만 공유하면 멤버가 바로 들어올 수 있습니다. 로그인 전이면 로그인 후 자동으로 참가됩니다.
- **드래그로 가능 시간 입력** — 시간표를 드래그해서 칠하면 자동 저장됩니다. 모바일 터치도 지원합니다.
- **곡별 멤버 관리** — 곡을 추가하고 곡마다 참여하는 멤버를 지정합니다.
- **결과 히트맵**
  - 전체 합주 또는 곡 여러 개를 골라, 해당 멤버 기준으로 가능한 인원을 색 농도로 표시
  - 칸에 마우스를 올리거나 탭하면 가능/불가능 멤버 확인
  - 전원이 가능한 시간대 목록 제공
  - 선택한 곡 조합을 URL로 공유 (`?songs=3,5`)
- **방장 기능** — 방 설정 수정, 방장 넘기기, 멤버 내보내기, 초대 링크 재발급, 방 삭제, 곡 변경 기록 열람

> 시간대는 한국 시간(Asia/Seoul) 기준입니다.

## 사용 방법

1. 사이트에서 아이디/비밀번호로 회원가입합니다. (이메일 필요 없음)
2. 방을 만들고 합주 후보 날짜와 시간 범위를 정합니다.
3. 초대 링크를 멤버들에게 공유합니다.
4. 각자 가능한 시간을 드래그해서 칠하고, 곡과 곡별 멤버를 등록합니다.
5. 결과 히트맵에서 전체 합주 또는 원하는 곡을 선택해 모두 모일 수 있는 시간을 확인합니다.

## 기술 스택

| 영역 | 사용 기술 |
|---|---|
| 프론트엔드 | React, TypeScript, Vite, React Router (UI 라이브러리 없이 CSS 직접 작성) |
| 백엔드 | Cloudflare Pages Functions |
| 데이터베이스 | Cloudflare D1 (SQLite) |
| 테스트 | Vitest |
| 배포 | Cloudflare Pages (GitHub 연동 자동 배포) |

Cloudflare 무료 플랜만으로 운영합니다.

## 프로젝트 구조

```
src/
  pages/        로그인, 회원가입, 방 목록, 초대 참가, 방 화면
  components/   시간 입력 그리드, 결과 히트맵, 곡 관리 등 UI 컴포넌트
  lib/          API 클라이언트, 결과 계산 등 순수 함수
functions/
  _lib/         암호화, 세션, DB, 입력 검증, 권한 확인
  api/          auth / rooms / songs API (미들웨어에서 세션·방 멤버 확인)
migrations/     D1 스키마 마이그레이션
scripts/        관리용 스크립트 (비밀번호 초기화)
```

## 로컬에서 실행하기

Node.js 22 이상이 필요합니다. 로컬 실행에는 Cloudflare 계정이 필요 없습니다.

```bash
npm install
npm run db:migrate:local   # 로컬 D1에 테이블 생성
```

터미널 두 개에서 각각 실행합니다.

```bash
npm run dev:api   # API 서버 (wrangler, http://localhost:8788)
npm run dev       # 프론트엔드 (vite, http://localhost:5173)
```

브라우저에서 http://localhost:5173 으로 접속합니다.

```bash
npm test          # 테스트
npm run build     # 타입 검사 + 프로덕션 빌드
```

## 보안

- 비밀번호는 PBKDF2-SHA256 + 랜덤 salt로 해시해 저장하며, 원본은 어디에도 저장하지 않습니다.
- 세션은 `HttpOnly`, `Secure`, `SameSite=Lax` 쿠키로 관리하고 DB에는 토큰 해시만 저장합니다.
- 방 관련 API는 모두 방 멤버인지 확인하며, 방장 전용 작업은 별도로 권한을 확인합니다.
- 다른 출처(Origin)에서 오는 상태 변경 요청은 거부합니다.
